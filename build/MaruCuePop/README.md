## MaruCue Pop

Copyright (c) 2026 omonomo ([https://omonomo.github.io//](https://omonomo.github.io//))

Google Fonts 等で提供されている [Hachi Maru Pop](https://github.com/noriokanisawa/HachiMaruPop) を等幅フォント化しました。

## HachiMaruPop からの変更内容

- 生成スクリプトにより機械的に半角文字と全角文字に振り分け、サイズやウェイトを調整しました。
- 半角文字と全角文字の比率は 3:4 です。
- OpenTypeの "ss01" または "cv01" フィーチャータグを有効にすると全角スペースを可視化できます。
- 手動で調整、改変したグリフ: 0 , . ; : (半角)、０ ， ． ； ： 敲 寂 (全角)
- 追加したグリフ: 㪣 (全角)、可視化した全角スペース
