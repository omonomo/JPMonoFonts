## Benishijimi

Copyright (c) 2026 omonomo ([https://omonomo.github.io//](https://omonomo.github.io//))

Google Fonts 等で提供されている [Zen Kurenaido](https://github.com/googlefonts/zen-kurenaido) を等幅フォント化しました。

## Zen Kurenaido からの変更内容

- 生成スクリプトにより機械的に半角文字と全角文字に振り分け、サイズやウェイトを調整しました。
- 半角文字と全角文字の比率は 1:2 です。
- ` のグリフクラスを「マーク」から「クラスなし」に変更しています。
- OpenTypeの "ss01" または "cv01" フィーチャータグを有効にすると全角スペースを可視化できます。
- 手動で調整、改変したグリフ: 0 I + \ ~ ´ (半角)、０ Ｉ (全角)
- 追加したグリフ: － ～ (全角)、可視化した全角スペース
