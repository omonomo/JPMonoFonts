## Yusei Marker (油性マーカー)

Copyright (c) 2026 omonomo ([https://github.com/omonomo/JPMonoFonts](https://github.com/omonomo/JPMonoFonts))

Google Fonts 等で提供されている [Yusei Magic (油性マジック)](https://github.com/tanukifont/YuseiMagic) を等幅フォント化しました。

## Yusei Magic からの変更内容

- 生成スクリプトにより機械的に半角文字と全角文字に振り分け、サイズやウェイトを調整しました。
- 半角文字と全角文字の比率は 3:5 です。
- OpenTypeの "ss01" または "cv01" フィーチャータグを有効にすると全角スペースを可視化できます。
- 手動で調整、改変したグリフ: 0 l * - , . ; : " ' @ ` { } | ´ (半角)、０ ｌ ， ． ； ： ＂ ＇ ｀ ｛ ｝ (全角)
- 追加したグリフ: 可視化した全角スペース
