## Potori (ポトリ)

Copyright (c) 2026 omonomo ([https://github.com/omonomo/JPMonoFonts](https://github.com/omonomo/JPMonoFonts))

Google Fonts 等で提供されている [Potta One (ポッタ)](https://github.com/go108go/Potta) を開発向けにカスタマイズしました。

## Potta One からの変更内容

- 生成スクリプトにより機械的に半角文字と全角文字に振り分け、サイズやウェイトを調整しました。
- 半角文字と全角文字の比率は 3:5 です。
- OpenTypeの "liga" フィーチャーを削除しています。
- OpenTypeの "ss01" または "cv01" フィーチャータグを有効にすると全角スペースを可視化できます。
- 手動で調整、改変したグリフ: 0 I j l * ` ´ Ħ Ố Ồ Ổ Ớ Ờ Ở Ỡ Ợ 通貨記号 (半角)、０ Ｉ ｊ ｌ ｀ ǉ (全角)
- 追加したグリフ: ＂ ＇ (全角)、可視化した全角スペース
